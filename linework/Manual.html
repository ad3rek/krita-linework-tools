Krita Linework Tools 0.1.5

Six tools appear in Krita's toolbox as a separate group. Icons follow the theme. Controls appear in Tool Options; show it through Settings → Dockers → Tool Options. Linework layers appear in Layers with their own icon. Control labels follow Krita’s selected interface language, with English fallback for missing translations. Catalogs include all 75 Krita locales; most require community review, and several have partial coverage. See docs/TRANSLATIONS.md for the coverage and contribution instructions.

Tool Options uses compact sections with a disclosure arrow. Click a section title to expand or collapse it without changing its values. Edit and Thickness place selection and point diameter first. Taper and connection sections start collapsed; colors and arrows follow Krita's theme.

Draw and edit

  • Brush: choose a Krita brush preset and draw on the canvas with mouse or stylus. Color, size, opacity, flow and preset are captured when the stroke starts.
  • Curve / Line: click to place points. Enter or right click finishes; Esc cancels. Line uses straight segments.
  • Edit: drag points, groups or strokes. The active point shows square handles. Normal handle dragging aligns the opposite handle; Alt-drag moves one side independently. Double click or Alt-click on a stroke inserts a point without deforming the curve. Delete removes selected points or fully selected strokes.
  • Thickness: select points and drag vertically or enter a nominal diameter in pixels. Side guides and a canvas indicator show the width. Recorded pressure remains independent for other brush sensors.
  • Erase: choose Erase line to remove crossed strokes or Erase points to reduce the diameter of existing anchors. Size, strength and tablet pressure control the circular footprint; zero-width anchors remain editable. Repeated samples do not build up during one gesture. Esc restores the result; each gesture is one undo step. Saving finishes an eraser gesture once.

Brush/Curve/Line configure the next stroke. Edit/Thickness modify the current selection. The first stroke creates a Linework layer when necessary; Tools → Scripts → New Linework Layer starts another. Selecting a Linework layer recovers its strokes. Switching to another Krita tool releases input; hiding Tool Options does not disable Brush.

Space-drag, middle mouse navigation, zoom and Ctrl-click color sampling follow Krita. Shift-drag changes brush size in Brush/Curve/Line and modifies selection in Edit/Thickness. Ctrl+Z/Ctrl+Shift+Z use Linework's session history, separate from native history and retained across Linework tool switches.

Selection modes and active-point lock

Tool Options → Selection offers automatic point/stroke selection, Points (anchors only) and Strokes (whole paths, including clicks on endpoints). In stroke mode, dragging moves the entire selected path. Lock active point keeps one anchor selected and ignores misses, Shift-click and Select All until unlocked; its handles and diameter remain editable. Edit and Thickness share this selection. Click radius defaults to 16 screen pixels, adjustable from 4–40 px, independent of canvas zoom. The nearest point/handle wins.

Multiple selection

Shift-click toggles points/strokes. Drag empty canvas to select points with a rectangle; Shift-drag adds, Esc cancels. Ctrl+A selects all strokes and points. Native Select Shapes selection is inherited on entering Edit/Thickness. Selected points are orange; the active point shows handles. Switching Edit/Thickness retains selection.

Point thickness affects selected points only: typing sets the same diameter even across different stroke base widths; dragging applies the same pixel difference to initial values. Range: 0–2000 px. Base width, opacity, minimum width, tapers and brush replacement affect strokes containing selected points. Mixed values show Multiple; typing applies to the group. Group edits are one undo step. Selection is not saved in .kra.

Merge points and join endpoints

In Edit → Points and connections, Shift-click to select anchors; the last selected is active. Merge points collapses consecutive points on one path, or welds two endpoints from different paths. At center averages position and diameter; At active point keeps the active values. Join endpoints retains both anchors and adds a connecting segment; joining both endpoints of one path closes it. The active stroke supplies brush, color and other style settings; source point diameters and recorded pressure are preserved. Exterior handles remain; internal tips lose their endpoint taper. These operations support linear paths, not arbitrary branches or nonconsecutive merges. Cancel keeps the original; completion is one undo step.

Change brushes on existing vectors

In Edit or Thickness, choose a new Krita preset. In Tool Options → Brush and color, choose Selected strokes or All strokes in the layer and click Apply brush (Aplicar pincel). Smooth line means a stroke without a raster preset. Points, handles, width, pressure, color, opacity and tapers are preserved. Independent diameter profiles retain their width across Pixel/Color Smudge/Quick Brush presets.

Preparation runs stroke by stroke with progress and Cancel. Cancel, Esc or switching tools/layers retains the old result. Application commits after all strokes are ready and is one undo step. Installed presets are unchanged.

Change stroke colors

In Edit or Thickness, changing Krita's foreground color recolors the selected strokes. Color picker changes are collected before rendering and become one undo step. Selecting a curve alone keeps its saved color. Use Tool Options → Brush and color → Apply color (Aplicar cor) to apply the foreground to Selected strokes or All strokes in the layer. Automatic changes always affect the selection, regardless of that button's scope. Native brushes are rerendered; smooth lines change their fill. Geometry, pressure, diameter, opacity and presets are preserved. Multicolor tips and preset color dynamics behave as in native Krita painting and may not yield a uniform foreground color.

Native smoothing and point reduction

Tool Options → Smoothing offers None, Basic, Weighted and Stabilizer, using the application’s own KisToolFreehandHelper/KisSmoothingOptions. Weighted provides distance, finishing, pressure smoothing and zoom scaling. Stabilizer provides sample count, delay, finish line and sensor stabilization; a circle shows delay distance. Krita 5.3/6.0 also exposes Pixel smoothing, minimum/maximum distances and their proportion lock. Options share Krita's configuration and are reread on activation. Changing them finishes the current stroke.

Every mode compacts new Brush strokes after native smoothing into fewer Bézier anchors. Geometric limits for None/Basic/Weighted/Stabilizer are 0.18/0.25/0.40/0.55 document px, tighter for thin tips. Pressure tolerance is at most 0.003 and independent diameter tolerance is 0.1 px. Corners, loops and stationary sensor changes are preserved. If work limits are reached or anchors cannot be reduced, the original remains. Existing strokes, click-created curves and imported OpenToonz vectors keep their points.

Pressure smoothing also filters recorded pressure. Physical tilt and rotation are not recorded. Without finish line, a Stabilizer stroke may end before the cursor. Esc cancels the stroke and timers. Saving or switching tools finishes and compacts the stroke before saving.

Editing previews and native transformations

During dragging, original affected appearances are hidden only from rendering and cached; previews replace them. Esc or tool/layer changes restore the confirmed result. Release rerenders and commits. Saving during point/handle editing keeps the last confirmed version; saving during an eraser gesture finishes it once. The cache is limited to 64 MiB. Brush preview sends new segments incrementally and reuses its internal image; expensive presets can still be slow.

Native Select Shapes move/scale/rotate/mirror operations update points and handles and replay the stored preset after the gesture. Native transformation undo references remain valid. Uniform scale changes width; nonuniform scale uses the geometric mean of X/Y factors. Random textures may change on replay. Whole-document resizing does not update centerline metadata.

Independent diameter

Drawing uses original stylus pressure. First diameter editing converts the preset's pressure-to-size contribution through Krita's KisCubicCurve into a separate profile. Presets without pressure size begin at constant diameter; smooth/OpenToonz strokes retain their radius polynomial.

Diameter is nominal tip size before minimum width/tapers. Texture, hardness and tip shape change the painted footprint. Drag either endpoint of the diameter guide to adjust thickness along its normal, or drag an anchor vertically. Guide handles use the configured screen-space click radius, including at high zoom and with a locked point. Unsupported edits restore the original appearance and keep the selection. Only Size sensors are replaced in a private preset; opacity, flow and other sensors keep recorded pressure. Direct control supports Smooth line and Pixel/Color Smudge/Quick Brush. Nonlinear sensor conversion can change interpolation between anchors, and other Size sensors stop contributing after explicit diameter editing.

Vectorize the active raster layer

Select a paint or file layer and use Tools → Scripts → Vectorize Layer to Linework. Choose light background or alpha detection, threshold, despeckling, accuracy and maximum width, then update preview. Confirm creates a new editable layer. Source pixels remain unchanged; source visibility can be restored with Linework undo.

Wheel zooms under the cursor; left/middle drag pans. +/- and the percentage control zoom. Fit or double click frames the image. Original-resolution pixels and cached geometry are used; comparison/preview updates retain the viewed region.

This is a reimplementation/port of the same OpenToonz Centerline algorithm inside Krita, pinned to 8c5345182b1c3d2ff011a1cf08dad067b6700f08. The original BSD-3-Clause core runs polygonization, straight skeleton, graph organization and quadratic fitting. Position and radius controls are elevated exactly to cubics without refitting. Sixteen synthetic fixtures match the unpatched core's controls exactly.

Light-background detection uses max(R,G,B) and alpha. Accuracy maps to penalty 10 − accuracy; maximum width is twice the radius limit. Alpha mode prepares grayscale for the same core. Preserve color/transparency samples appearance after detection; disabling it uses black. Use current Krita preset renders the detected geometry with that brush; preview remains geometric.

Input is limited to 32 million pixels, 10,000 strokes and 20,000 anchors per stroke. Extraction runs in a worker; Cancel creates no layer. Lineart is the intended input. TLV colormaps, NAA, filled regions, photographs and gradients are not reconstructed. Intersections are independent segments. Final rendering is Krita's, not OpenToonz's.

Animation

Every new Linework layer already supports animation. Drawing, New Linework Layer and raster vectorization create the same layer with an editable frame at time 0, pinned to the Animation Timeline. Open Settings → Dockers → Animation Timeline and create or duplicate frames directly there; no conversion script or second layer is needed. Existing vector Linework documents remain readable and editable without an automatic rewrite.

Create, duplicate, move, delete or clone frames in Krita's native Timeline. New Linework Frame and Duplicate Linework Frame in Tools → Scripts also accept a destination frame number. Drawing between keys edits the held frame; create a new key first for an independent drawing. Native duplicates are independent; linked clones share their drawing until made unique. Use the existing Linework tools and Tool Options to draw and edit the active frame.

Geometry and pixels share Krita's native undo stack. Playback hides editing guides and uses native raster frames, as do onion skins and raster export. Save as .kra to keep editable data for every frame. Schema 7 annotations retain geometry on reopening; older plugin versions reject this metadata. Saving during point editing cancels the unconfirmed edit; drawing and eraser gestures are finished before saving.

Select Shapes applies to legacy vector layers. New Linework paths are selected and edited with Linework Edit or Thickness; choose Strokes in Tool Options to select entire paths. Native raster painting or transforms are preserved and detected before a later Linework edit, but cannot be translated back to the original paths. Whole-layer duplication, cross-document frame transfer, automatic in-betweening and physical tablet validation are outside the current animation regression scope.

Save, compatibility and limitations

The Windows x64 package supports Krita 5.2.14, 5.3.3, 5.3.4, 5.3.4.1, 6.0.3, 6.0.4 and 6.0.4.1. It selects a matching native DLL and the application’s PyQt 5 or PyQt 6 binding. If Python Plugin Manager reports This native bridge requires Krita 5.2.14, replace the complete older plugin folder with this package and restart Krita. Unknown versions are rejected before loading native code; changing a version check does not provide ABI compatibility. Linux currently supports Krita 5.2.14 with compatible Qt 5.15.17 libraries.

Save as .kra to retain geometry, handles, pressure, diameter and presets. Native preset texture is raster and embedded in the Linework layer; SVG preserves appearance but not plugin editing. Presets/resources must remain installed to rerender. Saved appearance is visible without the plugin. New Linework layers use schema 7 for their frame data; the compatibility backend reads and edits older vector layers using schema 6. This build reads earlier documents; old plugins reject newer metadata.

Each stroke paints on transparency. Preset interaction with pigment in other layers is not reproduced. The dedicated Linework Erase tool edits stored paths and their thickness profiles. Physical tilt, rotation and velocity are not captured. No .sai2 import, curve cutting, arbitrary branching networks or wraparound canvas is provided. Whole-document resizing does not update stored geometry. Manual SVG edits are protected against overwrite.

The native bridge protects shape mutations with an outer busy wait, preventing shape-reading timers from running during worker writes. Restart Krita after installing an update. Use the matching x86_64 platform package and an application version listed above. Other application builds require native recompilation and validation. Physical tablets must be tested on each device.

OpenAI Codex assisted development. Ghidra 11.0.3 was used for static reverse engineering of Paint Tool SAI 2 feature strings and references. No SAI executable, proprietary assets or decompiled code are included. See the main README for screenshots, tests, scope and attribution.

To uninstall, close Krita and remove linework.desktop, linework.action and linework/ from the resource folder's pykrita/. Saved appearances remain visible.

Windows preview limitation: the full 743-stroke bulk brush/thickness/history regression did not finish under Wine. Large-layer replay/history and physical Windows hardware remain unvalidated. See README and docs/validation/windows-status.json.
